# Project Theme & Color Documentation

## Overview

This document defines the core colors used in the project, including headers, backgrounds, text, accents, cards, and dividers. Consistent use of these colors ensures visual harmony across the application.

## Color Palette

| Element                  | Color Hex | Description / Usage                                    |
| ------------------------ | --------- | ------------------------------------------------------ |
| **Header**               | #FFFFFF   | White, used for top navigation and headers             |
| **App Background**       | #FCF9F2   | Cream, main background of the app                      |
| **Secondary Background** | #F2EDE4   | Light neutral for sections, cards, or panels           |
| **Primary Action**       | #3D2B1F   | Espresso, for main buttons, CTAs, or highlights        |
| **Secondary / Accent**   | #A68A64   | Caramel, for secondary buttons, accents, or highlights |
| **Primary Text**         | #1A1614   | Deep Bean, main text color for readability             |
| **Cards / Sections**     | #FFFFFF   | White, card or section backgrounds                     |
| **Dividers**             | #E8E2D6   | Latte, subtle lines between sections or cards          |
